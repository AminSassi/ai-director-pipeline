# Camera Angles & Movements

Reference for camera decisions when breaking down scripts into shots.

## Shot Types

| Shot | Description | When to use |
|------|-------------|-------------|
| Extreme Wide | Landscape/establishing | Scene transitions, showing scale |
| Wide | Full scene with subjects | Establishing location |
| Medium | Waist-up | Dialogue, interviews |
| Close-up | Face/ detail | Emotion, reaction |
| Extreme Close-up | Eyes, hands, objects | Tension, intimacy |

## Camera Movements

| Movement | Description | Effect |
|----------|-------------|--------|
| Static | No movement | Stability, observation |
| Pan | Horizontal rotation | Following action, reveal |
| Tilt | Vertical rotation | Scale, power dynamics |
| Dolly in | Moving closer | Intimacy, focus |
| Dolly out | Moving away | Isolation, context |
| Tracking | Following subject | Engagement, journey |
| Crane | Vertical rise/fall | Grandeur, perspective |
| Handheld | Shaky, organic | Urgency, realism |

## Documentary-specific

- **Talking head**: Medium or close-up, static or slow dolly
- **B-roll**: Wide or medium, tracking or panning
- **Reenactment**: Match film look, use movement for drama
- **Archival**: Ken Burns effect (slow pan/zoom on still images)
