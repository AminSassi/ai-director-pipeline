# Prompt Quality Checklist

Use this checklist to review every prompt before presenting to the director.

## For Grok Imagine (video)

- [ ] Subject is clearly defined
- [ ] Action/movement is specified
- [ ] Camera angle and movement included
- [ ] Lighting described
- [ ] Cinematic/film style mentioned
- [ ] Pacing implied (slow, steady, dynamic)
- [ ] Under 80 words
- [ ] No conflicting instructions
- [ ] Matches the scene's emotional tone

## For Nano Banana 2 (image)

- [ ] Subject is the clear focal point
- [ ] Composition rule applied
- [ ] Lighting source specified
- [ ] Color palette/mood described
- [ ] Style (photorealistic/cinematic) included
- [ ] No ambiguous descriptions

## Common mistakes to catch

- Too many subjects (keep it simple, 1-2 per clip)
- Conflicting camera directions (e.g., "zoom in while pulling back")
- Vague mood (instead of "dark" → "dimly lit, blue tones, high contrast")
- Missing movement for video clips
- Overly long prompts (cut to essentials)
