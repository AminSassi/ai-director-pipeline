# Suno Music Prompt Template

## Format

```
[Score style], [BPM] BPM; [Opening description], then [build elements], [tension elements], [climax elements], and [pullback elements], [Texture], [Mix description], [Genre tags], [Mood tags], [Instrument tags]
```

## Example: True Crime / Chase Story

```
Cinematic documentary score, slow-build tension-driven hybrid at 70 BPM; near-silent opening with a single low drone, then precise ticking percussion, deep bass pulses, faint vinyl crackle, Uneven string stabs, suspenseful brass swells, explosive metallic hits, rapid ostinato, and a sparse piano pullback, Film grain texture, analog warmth, wide heavy mix with cold precision, dark ambient, deep, electronic, experimental, minimal, industrial, synthetic, orchestral, true crime, chase, fugitive, tension, mystery, thriller, low, rapid, cello, rock, glitch, alternative, tone, faint
```

## Key Elements

### BPM Range
- **60-65 BPM**: Slow, heavy, emotional
- **70-75 BPM**: Tension, suspense, chase
- **80+ BPM**: Action, fast-paced

### Opening Options
- Near-silent opening with a single low drone
- Near-silent opening with a single low digital tone
- Sparse piano notes
- Deep bass hum

### Build Elements
- Precise synth pulse
- Ticking percussion
- Deep bass drones
- Faint keyboard taps
- Vinyl crackle

### Tension Elements
- Uneven string stabs
- Suspenseful brass swells
- Ticking-clock tension
- Rising ostinato

### Climax Elements
- Explosive metallic percussion
- Rapid ostinato
- Heavy distorted guitars
- Industrial hits

### Pullback Elements
- Sparse cello pullback
- Sparse piano pullback
- Single sustained note
- Fade to silence

### Texture Options
- Film grain texture
- Glitchy film grain
- Analog warmth
- Digital coldness

### Mix Options
- Wide heavy mix with cold precision
- Tight focused mix
- Atmospheric reverb-heavy mix

### Genre Tags
- dark ambient
- experimental
- minimal
- industrial
- synthetic
- orchestral
- electronic
- alternative rock
- experimental rock

### Mood Tags
- true crime
- chase
- fugitive
- tension
- mystery
- thriller
- suspense
- heist
- escape
- pursuit

### Instrument Tags
- cello
- piano
